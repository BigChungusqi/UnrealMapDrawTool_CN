## 构建（同日）

- 本机环境：VS 2026 Community（`D:\Program Files\Microsoft Visual Studio\18\Community`，MSVC 14.51 / v145）**缺少 Windows SDK**（`Windows Kits\10` 只有 UnionMetadata），MSBuild 无法编译 Win32 程序；vcxproj 用的是 v143 工具集。
- 改用 VS Code 自带 MinGW-w64 g++ 16.2.0（x86_64-w64-mingw32）构建，需外部 GLFW：下载 `glfw-3.4.bin.WIN64.zip`，用 `lib-mingw-w64/libglfw3.a`；GLEW 用仓库里的 `src/glew64s.lib`（64 位，`glew32s.lib` 是 32 位，x64 链接会报 glewInit 未定义）。
- 链接参数：`-static -static-libgcc -static-libstdc++`，只需系统 DLL（opengl32/gdi32/shell32/user32 + UCRT）。产物 `Release/DrawMap_x64.exe`（6.1 MB）。
- 实测运行：窗口标题、初始设置、绘制工具栏、标签页、悬浮提示、文件对话框中文均正常；中文字体来自 C:/Windows/Fonts/msyh.ttc。
- 若要出官方 MSVC 版：需先装 VS 的 Windows SDK 组件，再 `msbuild vc_project\UnrealMapDrawTool.sln /p:Configuration=Release /p:Platform=x64`（v143 工具集需另装或改用 v145）。
